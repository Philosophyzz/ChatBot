# 二次元桌宠

默认角色为桃濑日和，另有虹色真央，两位使用已安装的 Live2D 官方免费示例；还保留三位原创 PNG 角色。角色切换同步改变桌宠立绘、窗口／托盘图标、角色介绍、提示词、触摸台词与语音配置。旧通用人设 ID 会映射到新角色。按本次清理要求，已有个人对话与记忆已清空。

| 角色 | 形象与性格 | 默认语音 |
|---|---|---|
| 桃濑日和 | 官方日和原造型，温柔明快的陪伴演绎 | Xiaoxiao |
| 虹色真央 | 官方真央原造型，橘发彩绘魔女，俏皮好奇 | Xiaoyi |
| 樱樱 | 樱花粉猫耳，茶屋看板娘，活泼、嘴硬心软 | Xiaoyi，轻快、较明亮 |
| 薄荷 | 薄荷绿兔耳，森林信使，温柔好奇 | Xiaoxiao，轻柔、稍慢 |
| 露娜 | 丁香紫魔女，星见钟楼学徒，安静机灵 | Xiaoxiao，更慢、稍低 |

角色介绍可在右键「角色介绍 / 初始记忆」查看，或在网页角色编辑器修改。每轮对话都会注入这段初始记忆，不依赖检索是否命中；不会把虚构身世写成用户的真实档案。清理个人记忆不会删除角色介绍。

## 桌面操作

右键 **ASMR（无语音）** 可选择纸张、刷拭、木质轻敲或组合，支持 45 秒试听、5/15/30 分钟定时、音量与暂停。也可输入「播放纸张 ASMR 15分钟」「停止ASMR」。播放期间暂停主动说话和免提监听，主动聊天会结束 ASMR。神经生成与训练说明见 [ASMR方案](ASMR生成与训练方案.md)。

| 操作 | 效果 |
|---|---|
| 滚轮／右键「桌宠大小」 | 35%～300% 连续缩放，滚轮每格细调 2%，约 16ms 一帧过渡；停止滚动后自动保存 |
| 轻点头部、脸颊、身体 | 三种不同台词与跳跃、飘心反馈 |
| 长按约 0.65 秒 | 拥抱反馈 |
| 双击 | 在桌面打开文字聊天框 |
| 拖动 | 移动角色，松开后限制在屏幕可见区域 |
| 点击嘴巴 | 投喂点心；透明区域不触发触摸 |
| 按住麦克风 | 松开后识别并发送语音 |
| 右键「打开网页」 | 唯一主动打开浏览器的入口 |

启动器、服务启动脚本、重新连接、双击、托盘点击均不会打开浏览器。后台 HTTP 服务仍会运行，供桌宠调用；没有打开浏览器时不会加载网页界面。

## 语音

默认使用现有 Edge 神经语音后端，通过各自的语速、音高和情感配置获得不同的二次元语气。需要联网，属于表现风格调整，不是已训练的真人声优模型。

右键「角色音色 / 参考音频…」可选择 Edge、IndexTTS2 或 GPT-SoVITS，并选择参考音频、填写对应台词。IndexTTS2／GPT-SoVITS 需要先部署引擎，具体见 [语音配置](语音配置.md) 和 [训练音色](训练音色.md)。网页角色编辑器还可以调整语速、音高与情感。语音后端失败仍沿用项目的降级机制，降级后的声音可能与目标风格不同。

## 模型调用

右键「模型调用：本地部署 / 外部 API…」，或网页「系统 → 模型调用模式」。

- 本地部署：填写本地兼容服务地址（如 `http://127.0.0.1:8080/v1`）和服务实际提供的模型名。项目自带 llama.cpp 默认档位为 `MiMo-V2.6-Distill-Qwen-9B-Q8_0`（Q8_0，配套图像投影）；Ollama／LM Studio 应填写各自地址和模型名。
- 外部 API：填写支持 Chat Completions 的接口根地址、模型名称和 API Key。聊天上下文及本轮召回记忆会发送给该服务；语音模型保持独立。并非所有厂商的专有接口都兼容。

保存后新请求立即使用新连接，重启也保留。设置保存在被 Git 忽略的 `config/local.yaml`，读取接口不返回密钥。外部 API 模式启动时跳过本地模型加载；已运行的本地模型不会被强制停止，可正常退出全部服务后重新启动以释放显存。

## Live2D

桃濑日和与虹色真央已启用原生 Live2D 渲染、自主动作、LLM 参数关键帧和音量口型。原有三位原创角色继续使用 PNG 动画。角色许可见 [Live2D资源许可](Live2D资源许可.md)。

如已有与角色匹配的完整 Cubism 3+ 模型目录：

```powershell
python -m pip install -r requirements-live2d.txt
```

右键「Live2D → 为当前角色导入模型…」，选择 `.model3.json`。模型目录应包含其引用的 `.moc3`、纹理及动作等文件，请保持目录位置不变。支持原生模型渲染、视线跟随、模型自带表情及说话状态的口型动画（不是音素级同步）。模型和运行库不可用时继续显示角色立绘。

可执行版在打包环境装有 Live2D 时自动收集运行库；安装运行库后需要重新运行 `scripts/build-pet.ps1`。两款模型已通过真实 GPU 渲染和切换检查；导入校验、缺失资源及 PNG 降级路径有回归测试。接入遵循 [live2d-py 的 PySide6 示例](https://github.com/EasyLive2D/live2d-py/blob/main/examples/main_pyside6_simple.py)。

## 启动与依赖

桌宠依赖在 `requirements-pet.txt`，服务核心与语音依赖分别为 `requirements.txt`、`requirements-speech.txt`。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start-pet.ps1
```

也可以双击 `启动聊天机器人.exe`。已运行的后端需要重启才能加载本次代码更新。

## 启动入口与模型目录

双击项目根目录 `启动聊天机器人.exe`，会自动启动本地服务和桌宠。只保留这一个日常入口；右键桌宠选「退出并停止全部服务」即可全部关闭。「退出」仅关闭桌宠，后台服务继续运行。网页仍需右键桌宠选「打开网页」。

本机全部模型权重已迁至 `D:/Models`（含 GGUF、Whisper、IndexTTS2、GPT-SoVITS）。`models` 的子目录和第三方工具原权重目录保留目录链接，兼容工具原路径，没有另一份权重。下载器和运行服务读取 `paths.models_dir`。

模型菜单、请求名称和文件名统一使用原名称，例如 `Qwen3.5-9B-Q4_K_M`、`Qwen3.6-27B-Q4_K_M-mtp`。角色列表包含桃濑日和、虹色真央、樱樱、薄荷、露娜；旧人设自定义配置已从活动目录清除。

## 情绪与后续开发

右键菜单统一通过「更换形象」切换角色，不再有重复的「切换人设」或「互动」菜单。网页的「记忆 → 情绪」可查看用户情绪、桌宠心情、判断来源和消息快照。

参见 [AAAAGENT 对比与情绪系统](AAAAGENT对比与情绪系统.md)，包含源码参考、实现方式、已知边界和后续开发建议。


## 主动陪伴与 vLLM 迁移

右键「陪伴场景」选择常态、电影、音乐或勿扰；「主动感知」总开关和「允许观察当前窗口画面」独立控制采集。底部显示当前状态。vLLM 的 Windows 组件已准备，需要重启 Windows 后从「底座模型 → 重启电脑后：继续安装 vLLM」完成安装和验证。详情见 [vLLM 与主动陪伴](vLLM与主动陪伴.md)。
